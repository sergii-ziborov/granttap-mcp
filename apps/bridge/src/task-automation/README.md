# Task automation

Public entry: `index.ts`. A fresh controller command may authorize automation
for one native execution, bound to its Project and current governance revision.
The grant is durable, independently removable, and stops applying when the
execution's Project or governance revision changes. Existing ordinary session
overrides remain bounded by the Project rule.

A chat grant can answer a verified ASK. Global and Project DENY, an unavailable
governance engine, paused automation, and disabled capabilities retain priority.
This changes no machine default or other chat. Tests live in `tests/`.
