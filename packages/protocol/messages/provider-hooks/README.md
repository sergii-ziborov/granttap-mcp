# Provider hook readiness and review

Public wire contract: [`index.ts`](index.ts), re-exported by the protocol schema.

Optional hook metadata extends the existing computer integration report. Each
GrantTap Codex event has independent configured, trusted, and enabled state.
Missing native reports remain unknown. Existing clients can omit all new fields.

A hook review request carries the selected computer, native hook key, displayed
hash, creation time, and correlation ID. The computer checks its current native
definition before writing trust. A result identifies the same computer and
request and includes the fresh native hook report. A successful receipt is not
proof that a hook has executed; usage remains a separate observation.

These messages are carried by the existing authenticated, encrypted device link.
No credentials, pairing secrets, or prompt content are part of this contract.
